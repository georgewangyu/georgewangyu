# Profile Vision

This repository should be the public GitHub profile surface that helps visitors
understand the account's work across agent systems, creator distribution tools,
and product experiments.

## Product Thesis

The profile is useful when it acts as a curated project map, not just a
biography. It should route people quickly to the strongest public repos and
make the through-line of the work obvious.

## Goals

- Keep featured projects current and easy to scan.
- Make agent infrastructure, creator tools, and products feel connected.
- Preserve links and badges as lightweight proof of public activity.
- Keep profile copy concise enough for a first-time visitor.

## Non-Goals

- Do not turn the profile README into a full portfolio site.
- Do not list every side project with equal weight.
- Do not expose private work context or operational details.
